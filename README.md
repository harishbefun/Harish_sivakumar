# Harish Siva Kumar — Portfolio

A responsive portfolio for Harish Siva Kumar, a mechatronics engineer. It uses plain HTML, CSS, and JavaScript, with project photography and CAD renders loaded from the existing `assets/` folders.

## Preview locally

Open `index.html` in a browser, or run a local static server from this folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

This portfolio is designed for the existing `harishbefun/Harish_sivakumar` repository. After the site files are pushed to `main`:

1. Open **Settings → Pages** in the repository.
2. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
3. GitHub will show the published site URL in the Pages settings after deployment finishes. A project site normally uses `https://harishbefun.github.io/Harish_sivakumar/`.

## Personalize before publishing

- The page links directly to project image folders in this repository. Keep those folders in place when moving the site.
- Add a LinkedIn link if you want one displayed; no LinkedIn URL was provided.
- Review phone, email, dates, and project details before making the site public.
- The Google Fonts import uses Manrope and DM Mono; system fallbacks are included.
